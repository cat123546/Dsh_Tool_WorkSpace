# 变更日志

## 2026-11-22 · v5 双击就能用

**新增**
- `词库.cmd` / `脱敏.cmd` / `检查.cmd`：双击即可运行的启动器，自动探测 Python，不用命令行
- `vocab.py` 无参数启动时进入中文交互菜单
- `mask.py` 新增 `--auto`：自动把输出放到 `_scratch/<日期>-<输入名>-处理/脱敏/`
- `mask.py` 启动时检测 `词库.csv` 是否比 `10-精确.json` 新，是则自动同步，省掉手动同步这一步

**变更**
- 所有脚本改为 ASCII 文件名（`mask.py` / `check.py` / `evaluate.py` / `resolve.py` / `vocab.py`）。
  原因：cmd 在 `chcp 65001` 之后会用 UTF-8 解析批处理文件里的中文文件名，导致路径乱码。
  中文保留在界面提示、文档和 `.cmd` 文件名里。
- 启动器内的提示文字改为英文，避免 GBK/UTF-8 混用导致的乱码；
  中文输出全部由 Python 打印，显示正常。

**验证**
- `词库.cmd 查看 人员` 正常输出
- 双击模拟（无参数）能弹出中文菜单
- `脱敏.cmd` 处理真实 4.6 MB PDF：提取 5073 字符，残留 0，自动落到 `_scratch/`
- `检查.cmd`：规则校验通过，评测 94% / 100%

## 2026-11-22 · v4 词库.csv 管理

**新增**
- `词库.csv`：精确层词表的人工编辑界面，六列中文（类别/词/变体/占位符/启用/备注）
- `vocab.py`：`同步` / `查看` / `加` / `停用` / `预览` 五个子命令
  - `同步` 把 CSV 编译成 `10-精确.json`，并逐条打印「这个词会被替换成什么」
  - `预览` 拿一句话试效果，不用真跑文档
  - `停用` 保留行只改「启用」列，不破坏历史
- `规则/词库说明.md`：每一列填什么、填了产生什么效果、常见场景怎么做

**变更**
- 精确层规则改为由 CSV 生成，`10-精确.json` 顶部标注「不要手工编辑」
- 规则 id 由 `X-001`~`X-201` 重编为 `X-001`~`X-013`（按 CSV 行序）

**回归**
- 迁移后 13 条规则全部保留：校验通过，评测仍为召回 94% / 精确率 100%

## 2026-11-22 · v3 还原能力

**新增**
- `mask.py` 输出 `_glossary.tsv`（占位符 -> 原值），用于交付前把占位符换成人能看懂的名字
- 一致性映射改为**跨文件共享**：同一实体在整个任务里始终同一编号，不再按文件重置
- 新增 `resolve.py`：检查/还原文本中的占位符，只做精确匹配，改写的占位符列为「无法解析」
- 新增 `--no-glossary` 开关

**修复**
- `resolve.py` 还原时 tuple 取值错误
- 占位符正文用 `<...>`、文件名用 `[...]`，还原时需兼容两种写法

**测试**
- 脱敏 1 份真实会议纪要：场站 13、公司 2、人员 1，残留 0
- 造模型输出并还原：3 个占位符成功还原为原值，1 个编造的 `<设备_9>` 被正确识别为无法解析
