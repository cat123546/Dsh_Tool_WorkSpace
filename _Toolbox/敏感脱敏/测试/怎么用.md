# 试新规则的地方

正式规则在 `../规则/`。**这里的规则不参与正常运行**，脱敏脚本默认只读 `../规则/`。

## 为什么要分开

- 试验规则不会污染正式词表
- 试错了直接删这个文件，正式规则毫发无损
- 正式运行时，脚本永远只从 `../规则/` 加载，测试目录被完全忽略

## 怎么试一条新规则

1. 从 `../规则/` 复制一个文件到这里，改名，例如 `试验-精确.json`
2. 在复制出来的文件里改规则（加词、改正则都行）
3. 跑的时候用 `--rules` 指向本目录：

```powershell
python mask.py --src 输入资料/某任务 --out _scratch/某任务-处理/脱敏试 --rules 测试 --dry-run
```

4. 看统计和残留，确认有效后，把**通过的那几条**追加进 `../规则/` 对应文件
5. 在 `../变更日志.md` 追加一行：改了什么、为什么、日期
6. 本目录的试验文件可以留着下次继续试，也可以删

## 注意

- 不要把试验规则直接写进 `../规则/`，改错了会污染正式结果，且没有对照
- 试完通过后，正式规则里的那些条目要**重新跑一次** `check.py` 和 `evaluate.py`
- 试验规则里如果引用了新词，记得同步更新 `../标注集.json`，否则评测测不到它
