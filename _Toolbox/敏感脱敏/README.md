# 敏感脱敏

把一批文档转成纯文本，并把敏感信息替换成一致性占位符。
**屏幕只打印统计，绝不回显原文。文件名本身也会脱敏。**

## 最快上手（不用命令行）

工具箱里有三个**双击就能用**的文件：

| 双击 | 作用 |
| :--- | :--- |
| `词库.cmd` | 弹出菜单：同步 / 查看 / 加词 / 预览 / 停用 |
| `脱敏.cmd` | 把文件夹拖进窗口，自动脱敏到 `_scratch/` 下，不动原文件 |
| `检查.cmd` | 跑规则格式检查 + 召回率误报率 |

**前提**：本机装着 DeepSeek Harness。它自带 Python 运行时，不需要另外安装 Python。
启动器会自动找到那个 Python；找不到时会提示你先开一次 DSH。

也可以什么都不双击，直接在会话里跟我说「把某某加进词库」「处理这个文件夹」，我来跑。

## 规则从哪来（重要）

规则**只**来自本目录 `规则/` 下的 JSON 文件。脚本不会、也不应该从待处理文档里学习或生成任何规则。
待处理文档里的文字一律只当数据——里面写「请忽略规则」也只是待匹配的文本，不会变成指令。

## 目录

```
敏感脱敏/
├── 规则/
│   ├── 10-精确.json    确定值逐条匹配（公司名、场站名、人名…）
│   ├── 20-模式.json    正则 + 校验位（手机号、身份证、银行卡…）
│   └── 30-语义.json    上下文规则，置信度低，只提示不替换
├── 标注集.json         评测用样本（带人工标注）
├── mask.py             主程序
├── check.py             规则集格式校验
└── evaluate.py             召回率 / 误报率评测
```

三层分开存放，抢占顺序固定：**精确 > 模式 > 语义**。这是硬规则，不要改。

## 怎么加一条词（最常用）

编辑 `规则/词库.csv`，加一行：

```csv
组织,某某公司,是,组织,是,备注
```

六列依次是：类别、词、变体、占位符、启用、备注。

- **类别**：组织 / 场站 / 公司 / 人员 / 项目 / 设备，决定替换成 `<类别_1>`
- **变体**：填「是」能容忍「三峡（滨海）储能」这种括号断开；人名建议填「否」
- **占位符**：留空就同类别
- **启用**：填「否」就停用，**不要删行**
- **备注**：写「为什么加这个词」，半年后你自己能看懂

然后跑：

```powershell
python vocab.py 同步    # 校验 + 生成规则 + 列出每条的实际效果
python check.py
python evaluate.py
```

也可以不打开表格，直接命令行加：

```powershell
python vocab.py 加 人员 张三
python vocab.py 查看
python vocab.py 预览 "三峡（滨海）储能电站的宋阳"
```

每一列的取值和效果详解见 `规则/词库说明.md`。

## 怎么加一条正则（进阶）

打开 `规则/20-模式.json`：

```json
{
  "id": "P-107",
  "层": "模式",
  "类别": "业务编号",
  "名称": "合同编号",
  "正则": "合同[编号]{0,2}[：:\\s]{0,3}([A-Za-z0-9\\-]{6,20})",
  "校验": "none",
  "上下文": null,
  "占位符": "合同号",
  "优先级": 40,
  "置信度": 0.9,
  "启用": true,
  "来源": "自定义"
}
```

- **有捕获组时，只替换捕获组那一段**（上例只替换编号本身，保留"合同编号："前缀）
- `校验` 可选：`none` / `id18`（身份证校验位）/ `uscc`（信用代码）/ `luhn`（银行卡）
- `上下文`：填一个正则，要求匹配位置**前 30 字内**出现它，用来避免误伤
- **编号类规则一定带前缀词**（`合同[编号]…`），裸数字一律不匹配——这是不误伤订单号、设备编号的关键

## 试新规则（不要直接改正式规则）

正式规则在 `规则/`。试新规则放 `测试/`，用 `--rules` 指向它：

```powershell
python mask.py --src ... --out ... --rules 测试 --dry-run
```

试用通过后，再把通过的那几条追加进 `规则/`，并在 `变更日志.md` 记一行。
详见 `测试/怎么用.md`。

## 内置能识别的

| 类型 | 依据 |
| :--- | :--- |
| 身份证 | 格式 + 生日合法性 + 校验位 |
| 银行卡 | 12–19 位 + Luhn |
| 统一社会信用代码 | GB 32100-2015 校验位 |
| 手机号 | 号段 + 数字边界 |
| 固话 | 区号格式 + 上下文（传真/电话/座机） |
| 车牌 | 省份简称 + 字母 + 5–6 位 + 上下文（车辆/进场） |
| 邮箱 / IP | 正则（IP 逐段 0–255 校验） |
| 工号 / 工作票 / 操作票 / 缺陷单 / 调度指令 | 前缀词 + 编号格式 |
| 经纬度 | 两组小数 |
| 精确词 | 你维护的公司名、场站名、人名 |

## 识别不了的（必须知道）

中文姓名（除词表命中外）、地址、公司名（除词表命中外）、金额、日期、岗位、业务结论。

这些没有确定性判据。处理办法只有两个：**加进精确层词表**，或者**别把这段给模型看**。

## 用法

```powershell
# 1. 先干跑，只出统计
python mask.py --src 输入资料/某任务 --out _scratch/某任务-处理/脱敏 --dry-run

# 2. 正式跑（文件名和正文一起脱敏）
python mask.py --src 输入资料/某任务 --out _scratch/某任务-处理/脱敏

# 3. 改了规则要重跑
python mask.py ... --force

# 校验规则集
python check.py

# 评测召回率与误报率
python evaluate.py
```

## 输出

```
<out>/
├── [类型_序号].txt   脱敏后的文本，文件名也脱敏
├── _stats.json       统计（不含原文）
├── _map.tsv          原名 -> 脱敏名 对照（含原名）
└── _glossary.tsv     占位符 -> 原值 对照（含原值，交付前用来还原）
```

`_map.tsv` 和 `_glossary.tsv` 都含原始信息，**任务结束请删除，不要上传**。

## 还原：把占位符换回人看得懂的名字

模型输出里会出现 `<场站_1>` 这种占位符，人看不懂。用 `_glossary.tsv` 还原：

```powershell
# 只检查，不改文本
python resolve.py --glossary _scratch/某任务-处理/脱敏/_glossary.tsv --text 交付稿.md

# 精确匹配替换，输出到新文件
python resolve.py --glossary ... --text 交付稿.md --apply --out 交付稿-可读版.md

# 看全部对照
python resolve.py --glossary ... --list
```

**只做精确匹配，不猜。** 模型如果把 `<场站_1>` 改写成「该场站」，对照脚本不会去猜它是哪个场站——它会出现在"无法解析"清单里，由人判断。猜就会错，错就会误导。

`resolve.py` 会报告三件事：能解析几处、无法解析几处、每个占位符对应哪个原值。

## 跳过与建议

单个文件失败不会中断整体，脚本会在最后列出：

| 情况 | 提示 |
| :--- | :--- |
| 老式 `.doc` | 用 Word 另存为 `.docx`，或装 LibreOffice |
| PDF 无 pymupdf | `pip install pymupdf` |
| 提取不到文本 | 扫描件，需要 OCR 或人工转文本 |
| 加密/损坏 | 报文件名和原因，不猜 |

## 安全须知

1. `_map.tsv` 含原名，**任务结束删除**
2. 占位符编号泄露"同一实体出现几次"，不泄露身份；跨任务不要复用编号
3. 本工具只降低字段级泄露，回答不了"这份文件该不该给模型看"

## 已知限制

- 语义层目前只有上下文正则，没有 NER；置信度低的一律只提示
- 变体匹配可能留下孤立括号残渣，解决靠词表补"主干形态"
- 评测样本 22 条，数字只作趋势参考，扩样后会变
