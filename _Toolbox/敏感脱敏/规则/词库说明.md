# 词库说明

你只需要编辑 `词库.csv` 一个文件，然后跑 `python vocab.py 同步`。
下面写清楚每一列填什么、填了会产生什么效果。

## 六列，一眼看懂

| 列 | 填什么 | 填了的效果 |
| :--- | :--- | :--- |
| 类别 | 组织 / 场站 / 公司 / 人员 / 项目 / 设备，也可以自己起 | 决定默认替换成什么标签 |
| 词 | 要脱敏的原词，至少 2 个字 | 文档里出现这个词就被替换 |
| 变体 | 是 / 否 | 是=容忍括号和空格断开；否=必须一字不差 |
| 占位符 | 留空就同类别 | 决定显示成 `<组织_1>` 还是 `<别的_1>` |
| 启用 | 是 / 否 | 否=不生效，但行保留 |
| 备注 | 随便写 | 不参与匹配，只给你自己看 |

## 类别：填了会变成什么

| 你填的类别 | 文档里的词会被换成 | 什么时候用 |
| :--- | :--- | :--- |
| 组织 | `<组织_1>` | 集团、分公司、上级单位全称 |
| 场站 | `<场站_1>` | 电站、储能站、项目基地 |
| 公司 | `<公司_1>` | 外部合作方、供应商 |
| 人员 | `<人员_1>` | 真实姓名 |
| 项目 | `<项目_1>` | 项目代号、工程名 |
| 设备 | `<设备_1>` | 设备名、设备编号 |

也可以自己起类别（比如「合同方」），替换标签会自动跟着用。

**为什么要分类**：模型看到 `<组织_1> 向 <人员_1> 汇报` 能理解角色关系；
如果全替换成同一个标签，关系就丢了，分析质量会下降。

## 变体：开还是关

| 设置 | 效果 | 例子 |
| :--- | :--- | :--- |
| 是 | 容忍词中间插入括号、空格、顿号、连字符（最多 2 个） | 词「三峡滨海储能」能中「三峡（滨海）储能」「三 峡 滨 海 储 能」 |
| 否 | 必须一字不差 | 词「宋阳」只中「宋阳」 |

**建议**：
- 单位名、场站名 → **开**（真实文档里常见「三峡（滨海）储能科技有限公司」这种写法）
- 人名 → **关**（开着容易误伤，比如排版产生的空格会被当成变体）

## 占位符：决定标签长什么样

留空就自动用「类别」。填了就用你填的。

比如类别填「公司」、占位符填「甲方」，替换结果是 `<甲方_1>` 而不是 `<公司_1>`。

**编号规则**：同一类别（或同一占位符）的同一个词，在整个任务里永远得到同一个编号。
这样模型能看出「这个人和上一段那个人是同一个人」，但不知道他是谁。

## 启用：怎么停用而不删

填「否」就停用，但这一行还在。

**不要删行**。删了以后就查不到「这条规则曾经存在过」，也没法追溯为什么当初加它。
停用后随时可以改回「是」。

## 备注：写什么最有用

写**为什么加这个词**，比写「某某单位」有用得多。例如：

```
2026-11 新增，来自三峡滨海项目会议纪要
主干形态，别删，否则带后缀的名字会漏
外部供应商，合同里出现
```

半年后你自己看这一列，就知道能不能停用。

## 完整例子

```csv
类别,词,变体,占位符,启用,备注
组织,长江电力,是,组织,是,集团下属单位
场站,三峡滨海储能,是,场站,是,主干形态，别删
人员,宋阳,否,人员,是,人名建议关变体
公司,协鑫新能源,是,公司,是,外部合作方
```

跑一次看看效果：

```powershell
python vocab.py 预览 "三峡（滨海）储能电站的宋阳，向协鑫新能源汇报"
```

输出：

```
原文: 三峡（滨海）储能电站的宋阳，向协鑫新能源汇报
脱敏: <场站_1>的<人员_1>，向<公司_1>汇报
```

## 常见场景怎么办

| 遇到的问题 | 怎么做 |
| :--- | :--- |
| 某个单位名漏了 | 加一行，类别填「组织」 |
| 某个词误伤了正常文字 | 把短词换成更长的形态；或者把「变体」改成「否」 |
| 换项目了，旧词不用了 | 「启用」改「否」，**不要删行** |
| 一次加几十个词 | 用 Excel 打开 `词库.csv`，加完另存为「CSV UTF-8」 |
| 想看看现在有什么 | `python vocab.py 查看` |
| 不确定加的词会不会中 | `python vocab.py 预览 "一句话"` |

## 加完词必做

```powershell
python vocab.py 同步    # 校验并生成规则，会列出每条规则的替换效果
python check.py         # 规则格式
python evaluate.py         # 召回率有没有变化
```

## 两个坑

1. **Excel 存 CSV 可能变成 GBK**，脚本能读，但换个机器可能乱码。稳妥做法是另存为「CSV UTF-8」。
2. **纯数字的词（工号等）会被 Excel 转成科学计数法**。用 `python vocab.py 加 设备 12345678` 这种命令行方式加，或者把 Excel 那列设成文本格式。
