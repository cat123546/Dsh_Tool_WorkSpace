# 使用入门

## 三句话

1. **普通文件**丢 `输入资料\`，**敏感文件**丢 `输入资料\敏感\`
2. 跟 AI 说你要做什么
3. 结果在 `输出结果\`

任务目录由 AI 建、文件由 AI 归类，你不用管。

---

## 双击就能用的

| 双击这个 | 作用 |
| :--- | :--- |
| `_Toolbox\自检.cmd` | 检查工作区有没有坏（改了规则/工具之后跑一次） |
| `_Toolbox\备份.cmd` | 备份 SPEC、词库、数据这些不在 git 里的东西 |
| `_Toolbox\敏感脱敏\脱敏.cmd` | 把文件夹拖进窗口，自动脱敏 |
| `_Toolbox\敏感脱敏\词库.cmd` | 菜单：加词 / 查看 / 预览 / 停用 |
| `_Toolbox\敏感脱敏\检查.cmd` | 跑规则格式检查和召回率评测 |

**其他所有 `.py` 不用自己跑**，直接跟 AI 说"用 xxx 处理一下"就行。

---

## 敏感文件怎么放

判断标准：

| 文件里有 | 放哪 |
| :--- | :--- |
| 人名、手机、身份证、银行卡 | `输入资料\敏感\` |
| 公司全称、项目代号、场站名 | `输入资料\敏感\` |
| 工号、工作票号、缺陷单号 | `输入资料\敏感\` |
| 纯技术资料、公开标准 | `输入资料\` |
| 拿不准 | **放敏感**（多做一次脱敏只多几秒） |

**放错会怎样**：放根目录的文件 AI 会原样读进上下文。如果里面有人名，就进去了。

## 第一次用要做什么

```powershell
# 1. 建三个数据目录（git 不跟踪空目录）
mkdir 输入资料, 输出结果, _scratch

# 2. 建历史索引
"# 归档历史`n`n| 子目录 | 用途 |`n| :--- | :--- |`n| （暂无） | |" | Out-File 输出结果\HISTORY.md -Encoding utf8

# 3. 复制空词库模板
copy _Toolbox\敏感脱敏\规则\词库-空模板.csv _Toolbox\敏感脱敏\规则\词库.csv

# 4. 验证
python _Toolbox\selfcheck.py
```

做完这四步，工作区就能用了。

## 出问题怎么办

| 现象 | 原因 | 怎么办 |
| :--- | :--- | :--- |
| 双击 `.cmd` 一闪而过 | 找不到 Python | 先启动一次 DeepSeek Harness |
| CSV 打开乱码 | 编码丢了 | 双击 `词库.cmd` 跑一次同步会补回 |
| 脱敏残留不为 0 | 规则漏了 | 加词或收紧正则，重跑 |
| 文件被跳过 | 格式不支持 | 按提示装库或转格式 |
| 规则改了没生效 | CSV 没同步 | 跑 `自检.cmd` 看第 5 项 |

## 更新框架

```powershell
git pull
```

如果提示冲突，说明你改过框架文件——那些文件**不应该改**。先 `git checkout -- <文件>` 恢复，再 pull。

## 记住一条

**`AGENTS.md` 和 `_Toolbox\` 是公共部分，不要改。**

要加规则、加工具，提给维护者，由他发布新版本。你改了会导致后续更新冲突。
