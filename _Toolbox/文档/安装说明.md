# 安装说明（交给 AI 执行）

> 这份文件是给**接收方的 AI** 看的。请按步骤逐条执行，每步都有验证方法，做完一步再进下一步。
> 不要跳过验证，也不要"顺手优化"目录结构。

## 前置条件

| 项目 | 要求 | 检查命令 |
| :--- | :--- | :--- |
| 操作系统 | Windows 10/11 | `[environment]::OSVersion` |
| Git | 2.30+ | `git --version` |
| DeepSeek Harness | 已安装并启动过至少一次 | 存在 `$env:USERPROFILE\.dsh\dsh-runtimes` |

**Git 没装的话**，执行：

```powershell
winget install --id Git.Git -e --source winget --accept-source-agreements --accept-package-agreements
```

装完**必须新开一个终端**，否则 PATH 不生效。

## 第 1 步：选择安装位置

建议装在一个**独立目录**，不要放在桌面或下载目录（那些位置容易被清理，也可能带 Windows 的"来自网络"标记）。

```powershell
$ws = 'D:\DSH_WorkSpace'      # 按需修改
New-Item -ItemType Directory -Force -Path (Split-Path $ws) | Out-Null
```

## 第 2 步：克隆框架

```powershell
git clone https://github.com/cat123546/Dsh_Tool_WorkSpace.git $ws
cd $ws
```

**验证**：`ls` 应该看到 `AGENTS.md`、`README.md`、`_Toolbox`。

如果提示仓库需要认证，说明仓库是私有的，需要先让仓库所有者添加你的 GitHub 账号为 Collaborator。

## 第 3 步：建数据目录

git 不跟踪空目录，所以要手动建：

```powershell
New-Item -ItemType Directory -Force -Path '输入资料','输入资料\敏感','输出结果','_scratch' | Out-Null
```

**验证**：`ls` 能看到这四个目录。

## 第 4 步：建历史索引

```powershell
@"
# 归档历史

| 子目录 | 用途 |
| :--- | :--- |
| （暂无） | |
"@ | Out-File '输出结果\HISTORY.md' -Encoding utf8
```

## 第 5 步：初始化词库

```powershell
Copy-Item '_Toolbox\敏感脱敏\规则\词库-空模板.csv' '_Toolbox\敏感脱敏\规则\词库.csv'
```

**说明**：`词库-空模板.csv` 是框架带的示例，复制成 `词库.csv` 后就可以往里加本单位的词。
`词库.csv` 是本地文件，不会被 git 跟踪，所以每个人可以有自己的词表。

## 第 5b 步：初始化候选观察区

```powershell
Copy-Item '_Toolbox\文档\观察区-空模板.md' '_Toolbox\文档\观察区.md'
```

**说明**：同词库的道理——`观察区.md` 是你本地记录候选脚本的地方，不会被 git 覆盖。
`观察区-空模板.md` 只是模板，不要往里写东西。

## 第 6 步：装 Python 依赖（按需）

脱敏工具处理 PDF 需要 `pymupdf`：

```powershell
pip install pymupdf
```

DeepSeek Harness 自带的 Python 可能已经装了，先试跑一次，报错再装。

## 第 7 步：验证

```powershell
python _Toolbox\selfcheck.py
```

**期望结果**：`0 个错误，0 个警告`。

- 如果报"没有框架清单"——正常，说明清单还没生成，可以忽略（这条只对发布端有用）
- 如果报"词库未同步"——跑 `python _Toolbox\敏感脱敏\vocab.py 同步`
- 如果报"某工具 --help 失败"——多半是缺依赖，按报错装库

## 第 8 步：冒烟测试

```powershell
# 造一个测试文件
'测试：电话 13800138000，身份证 110101199001011237' | Out-File '_scratch\测试.txt' -Encoding utf8

# 脱敏
python _Toolbox\敏感脱敏\mask.py --src _scratch\测试.txt --out _scratch\测试输出

# 看输出：应该看到 <手机号_1> 和 <身份证_1>
Get-Content '_scratch\测试输出\测试.txt'
```

**期望**：两个敏感值都被替换成占位符。

完成后删除测试文件：

```powershell
Remove-Item '_scratch\测试.txt','_scratch\测试输出' -Recurse -Force
```

## 日常使用

```powershell
# 更新框架
git pull

# 检查工作区健康
python _Toolbox\selfcheck.py

# 备份本地数据（不在 git 里的东西）
python _Toolbox\backup.py
```

## 常见问题

| 问题 | 原因 | 解决 |
| :--- | :--- | :--- |
| `git pull` 报冲突 | 你改过框架文件 | `git checkout -- .` 放弃本地改动再 pull |
| 双击 `.cmd` 一闪而过 | 找不到 Python | 先启动一次 DeepSeek Harness |
| 自检报"框架文件不一致" | 框架被改过 | `git checkout -- .` 恢复 |
| CSV 乱码 | 编码丢了 | 跑一次 `词库.cmd` 同步 |
| 中文乱码 | 终端编码 | `chcp 65001` |

## 禁止事项

1. **不要修改 `AGENTS.md` 和 `_Toolbox\` 下的文件**——它们是公共部分，改了会导致下次更新冲突
2. **不要删除 `.gitignore`**——它保护着你的数据和敏感文件不被提交
3. **不要往 `输入资料\敏感\` 之外放敏感文件**——放错位置 AI 会直接读进上下文

## 需要定制时怎么办

- 想加规则 → 提给维护者，由他发布新版本
- 想加自己的工具 → 放在 `项目目录\` 下，不要放 `_Toolbox\`
- 想改脱敏词表 → 改 `_Toolbox\敏感脱敏\规则\词库.csv`（这个文件是本地私有的，随便改）
