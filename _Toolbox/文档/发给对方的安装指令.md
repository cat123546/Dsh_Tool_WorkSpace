# 发给对方的安装指令

把下面整段**复制粘贴**给对方的 AI 即可。它会自己装好。

---

## 可直接复制的指令

```
请帮我安装一个工作区模板。

仓库地址：https://github.com/cat123546/Dsh_Tool_WorkSpace.git

请按顺序做：

1. 检查 git 是否已安装（git --version）。没装就执行：
   winget install --id Git.Git -e --source winget --accept-source-agreements --accept-package-agreements
   装完提示我新开终端（PATH 要重载才生效）

2. 把仓库 clone 到一个独立目录，建议 D:\DSH_WorkSpace，
   不要放桌面、下载文件夹或 OneDrive 同步目录

3. 进入该目录，按 _Toolbox/文档/安装说明.md 执行第 3 步到第 8 步：
   建四个数据目录、建 HISTORY.md、复制空词库模板、复制空观察区模板、
   装 pymupdf、跑自检、做冒烟测试

4. 每一步都按说明里的"验证"确认后再进下一步

5. 全部完成后告诉我：装在哪、自检结果、有哪些警告或跳过项

注意事项：
- 不要修改 AGENTS.md 和 _Toolbox/ 下的任何文件（它们是公共部分）
- 不要动我现有的其他目录和数据
- 遇到报错就停下来告诉我，不要自己猜着修
- 安装说明.md 里标了"禁止事项"的，严格遵守
- 最后提醒我：还需要在 DeepSeek Harness 里把这个目录打开为工作区，规则才会生效
```

---

## 装完之后你还要做一件事

**在 DeepSeek Harness 里把那个目录打开为工作区。**

这是唯一需要人操作的地方——`AGENTS.md` 只有在 DSH 把该目录当工作区时才会自动注入。
只 clone 不打开，规则不生效，AI 不会按新规矩做事。

## 安装会不会动到自己的配置

| 东西 | 会不会变 |
| :--- | :--- |
| DSH 的插件、模型、主题等设置 | ❌ 不动 |
| 全局规则 `~\.dsh\AGENTS.md` | ❌ 不动（会与工作区规则叠加，工作区更具体优先） |
| 已有的其他工作区 | ❌ 不动，可以并存 |
| 新建的那个文件夹 | ✅ 会创建 |
| DSH 的工作区列表 | ✅ 加一条记录（正常） |
| DSH 自带的 Python 运行时 | ⚠️ 可能装 `pymupdf`（PDF 提取需要） |

**关于 `pymupdf`**：装进的是 DSH 那个 Python，不影响系统其他程序。如果不想装，跳过第 6 步即可，PDF 功能用不了，其他一切正常。

## 装完之后，什么会被更新覆盖、什么不会

| 你的文件 | `git pull` 时 |
| :--- | :--- |
| `输出结果\` 全部 | ❌ 不会被覆盖（git 完全不跟踪） |
| `输入资料\` 全部 | ❌ 不会被覆盖 |
| `_scratch\` | ❌ 不会被覆盖 |
| `_Toolbox\敏感脱敏\规则\词库.csv`（你配的词） | ❌ 不会被覆盖 |
| `_Toolbox\敏感脱敏\规则\10-精确.json` | ❌ 不会被覆盖 |
| `_Toolbox\文档\观察区.md`（你记的候选） | ❌ 不会被覆盖 |
| `AGENTS.md`、`_Toolbox\` 下的其他文件 | ⚠️ 你没改过就正常更新；改过会冲突 |

冲突时 git 会**拒绝合并**而不是覆盖你的文件。恢复办法：`git checkout -- .` 放弃本地改动再 pull。

## 日常维护

```powershell
# 检查工作区健康（改了规则/工具之后跑）
python _Toolbox\selfcheck.py

# 更新框架
git pull

# 备份本地数据（词库、输出结果等不在 git 里的东西）
python _Toolbox\backup.py
```

## 如果对方 DSH 总弹审批框

那是 DSH 的权限预设（`workspace-write` 会逐次询问）。两个办法：

- 接受弹窗，多点几下
- 或在会话里输 `/permission danger-full-access` 切到不询问模式
