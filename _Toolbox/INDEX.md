# 工具索引

| 工具 | 用途 | 路径 |
| :--- | :--- | :--- |
| 敏感脱敏 | 文档转纯文本 + 三层规则驱动脱敏，文件名也脱敏，只回统计 | `_Toolbox/敏感脱敏/` |
| pdf提取 | PDF 页面体检 / 全文提取 / 指定页提图，全参数化 | `_Toolbox/pdf提取/` |
