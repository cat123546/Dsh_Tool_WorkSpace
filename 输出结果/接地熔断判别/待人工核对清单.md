## C. 原文表述存疑（均已由文献解决）

### C-1　"1.4U"与"2U"的 U 指什么 ✅ 已解决

- **结论**：**指相电压的倍数**。同类文献的对应表述是：

| 指标 | PDF 表述 | 同类文献表述 |
|---|---|---|
| 单相接地工频（稳态）过电压 | 1.4U 以下 | 控制在 **1.5 倍相电压**以内 |
| 弧光接地过电压（暂态） | 2U 以下 | 不超过 **2.0 倍相电压** |
| 对照：不接地/消弧线圈系统弧光过电压 | — | **3.0~3.5 倍相电压** |

- **依据**：《光伏电站 35 kV 集电系统小电阻接地参数精细化设计与保护灵敏度协同优化》等多个来源口径一致。
- **说明**：1.4 与 1.5 的细微差异可能来自不同标准或不同试验条件，**量级和物理含义是明确的**——U 是相电压。正文第 22.1 节已按此处理。

### C-2　"熔断相电压指示降低，其它两相电压不变" ✅ 已解决

- **结论**：这句话**成立**，且已被多篇文献作为标准的判别依据反复引用。例如：

> 接地相电压明显降低，而其余两相相电压升高为线电压……**如果其余两相电压没有升高为线电压，则应是高压熔丝熔断所引起。高压熔丝熔断与单相接地故障主要表现在全网是否异常、电压是否升至线电压。**

> 高压保险一相熔断，对地电压一相降低，**另两相不会升高**，线电压则会降低。

- **前提**：三只单相 PT 星接、一次中性点接地（35kV 最常见配置）。
- **重要补充**：文献还指出一个我初稿没写到的细节——**高压熔丝未完全熔断时，可能根本不发接地信号**。已补入正文第 13.2 节。

### C-3　"线路超过一百公里就不产生谐振" ✅ 定性已明

- **结论**：**谐振是否发生取决于"对地电容与 PT 励磁特性的匹配"，线路长度只是间接因素**，100 km 不宜当普适阈值记。
- **机理**：文献给出的谐振分布数据表明，对地电容增大时谐振频率下降、谐振电流显著增大：

| 对地电容 C | 谐振频率 | PT 电流峰值 |
|---|---|---|
| 25 nF | 50 Hz（基频） | 461 mA |
| 50 nF | 25 Hz（1/2 分频） | 622 mA |
| 250 nF | 20 Hz | 2690 mA |
| 500 nF | 10 Hz | 3000 mA |

- **对"100 km"的理解**：长线路/大电缆化意味着对地电容大，系统可能"远离参数谐振区"，从而不易发生某些类型的谐振——这与"线路越长越容易谐振"的直觉相反，也正是原文那句话想表达的。
- **正文处理**：第 12.4 节只保留定性结论，未采用 100 km 这个数字（稳妥）。

### C-4　"X 端绝缘水平与消谐器不匹配" ✅ 已解决（解释很具体）

- **结论**：这句看似含糊的话指向一个很实际的选型问题：

| 概念 | 说明 |
|---|---|
| **X 端** | PT 一次绕组的**尾端**（中性点端） |
| **全绝缘 PT** | X 端绝缘与首端同级 |
| **弱绝缘 PT** | X 端绝缘较低，高压尾端常与二次侧一同输出 |
| **LXQ（普通）** | 配全绝缘 PT |
| **LXQ(D)** | 配弱绝缘 PT，内置 D 元件**限制消谐器两端电压**，使其压在弱绝缘耐受水平之下 |

- **"不匹配"的后果链**：给弱绝缘 PT 配普通 LXQ → 系统异常时消谐器两端电压超过 X 端耐受 → 击穿 X 端绝缘 → PT 内部短路 → 熔断器熔断。
- **正文处理**：第 23.2 节已展开为完整的选型表与因果链。
